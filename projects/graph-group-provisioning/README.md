# Microsoft Graph Group Provisioning Lab

## Goal
Practice group provisioning with Microsoft Graph PowerShell and explore the permissions involved.

## What I did
- Created an app registration for lab use.
- Connected to Microsoft Graph with `Connect-MgGraph`.
- Created a security group through Microsoft Graph.
- Reviewed the `User.Read.All` permission and identified that admin consent was required.
- Noted sign-in limitations when using a consumer account.

## What I learned
Graph operations depend on permissions and consent. Reviewing access requirements helps keep identity automation controlled.

## Lab environment
Completed in a personal test tenant using sample data. No credentials, tokens, or real user information are included.
