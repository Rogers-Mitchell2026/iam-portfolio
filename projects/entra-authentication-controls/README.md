# Microsoft Entra ID MFA and Conditional Access Lab

## Goal
Explore MFA registration and how tenant security settings affect Conditional Access testing.

## What I did
- Registered Microsoft Authenticator for a test account.
- Reviewed Security Defaults and available sign-in activity.
- Attempted to test Conditional Access behavior.
- Observed that Security Defaults affected the test, so I could not validate a custom Conditional Access policy.

## What I learned
MFA registration, Security Defaults, and Conditional Access are related but distinct controls. Reviewing sign-in activity helps explain authentication outcomes.

## Lab environment
Completed in a personal test tenant using sample data. No production policies or user accounts were changed.
